# Assemblage R2 - étude en cours de qualification

[Vue isométrique](apercu-r2-isometrique.png) · [Vue de dessus](apercu-r2-dessus.png). La réouverture du fichier natif est testée dans FreeCAD ; le parseur OCCT installé avec CAD Viewer accepte le STEP. Ces contrôles de lecture ne qualifient pas les interfaces mécaniques.

Cet assemblage remplace les anciennes études d’arbres/fourches et le FT90M par les propositions R2, ajoute les paliers, supports, branche de direction et une partie des corridors de câbles. Il utilise les enveloppes légères des équipements. Les corridors hauts P03-P06 sont exclus parce que leurs supports et leurs descentes ne sont pas finalisés.

Les versions Free CAD ultra détaillées dans le dossier parent restent des vues **A2-R1**. Ne pas les considérer comme contenant ces corrections R2 ; leurs fichiers sont conservés sans écrasement. Les rapports R2 distinguent les contrôles réussis et les interférences encore ouvertes.
