# Rotules de biellettes

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **Tamiya 50592 — 5 mm Ball Connector**. Quantité prévue : **6 rotules utilisées ; un sachet annoncé de 10**.

Les rotules permettent les angles des biellettes sans transmettre une flexion inutile au palonnier.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| diamètre de boule | 5 mm |
| interface | Chapes Tamiya 50596 ; vissage et longueur de pied à vérifier |
| emploi | Fusées, renvois et liaison servo |
