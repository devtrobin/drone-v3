# Tiges de biellettes

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **Tiges filetées acier M3×0,5, coupées à longueur**. Quantité prévue : **3 tiges ; longueurs finales après implantation**.

Des tiges simples coupées sur mesure permettent d’adapter la direction au châssis fabriqué.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| filetage retenu | M3 au pas normal 0,5 mm |
| matière | Acier ; référence de fabrication, fournisseur non arrêté |
| longueur | À couper après relevé des centres ; pas de longueur TT-01 copiée |
