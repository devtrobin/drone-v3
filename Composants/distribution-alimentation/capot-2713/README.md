# Blue Sea 2713 - capot inclus dans le 2315

**Deux exemplaires déjà compris dans les deux 2315**, aucun achat séparé prévu. Capot de polycarbonate transparent compatible 2304/2305, fourni avec 2314/2315. Il se pose sur le bornier et laisse un accès latéral aux fils. Aucune étanchéité IP du 2315 n'est établie.

[STEP détaillé du capot](3D/bluesea-2713-capot-detaille.step). Parois, manchons, clips et logo sont reconstruits d'après les photos ; aucune cote de ces détails n'est publiée. La couleur claire est conservée, avec affichage opaque dans cet export pour compatibilité : ce modèle ne simule pas la transparence optique réelle.

Le repère Z du capot est celui du bornier complet : son dessous n'est pas à zéro. [Cotes et repères](../cotes.md), [assemblages](../3D/README.md), [fiche constructeur](https://www.bluesea.com/products/2713/MiniBus_BusBar_Cover_for_PN_2304_and_2305).
