# Blue Sea MiniBus 2315 - quantité deux

Une unité comprend le bornier commun à quatre goujons #10-32 et le capot 2713. Le 2305 désigne la variante sans capot. Le 2314 comporte cinq vis et deux goujons : ce n'est pas la variante retenue.

Le modèle [ensemble fermé](3D/bluesea-2315-complet-detaille.step) et le [bornier ouvert](3D/bluesea-2305-borniers-sans-capot-detaille.step) reproduisent le socle noir, la barre étamée, les quatre goujons filetés et les écrous à flasque dentée. Le matériel de fixation au châssis et le faisceau sont absents. Les dimensions non cotées sont estimées ; aucun matériel reçu n'a été mesuré.
