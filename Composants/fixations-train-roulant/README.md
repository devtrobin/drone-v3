# Fixations du train roulant

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **Tamiya 50594, 9805557, 50577, 9805945 et 50582**. Quantité prévue : **4 goupilles, 4 écrous de roue, 4 vis de pivot avant et les pivots des renvois ; compléments châssis après implantation**.

Les fixations et pièces d’appui sont nécessaires au montage ; ni les axes ni les fusées ne constituent un train roulant complet.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| goupilles de roues | 50594 : Ø2×10 mm, quatre utilisées ; vérifier celles incluses dans 53569 |
| écrous de roues | 9805557 : écrous nylstop à flasque de 4 mm, MC4 dans la notice |
| pivots de fusées | 50577 : vis autotaraudeuses 3×10 mm, avec pièces A6 selon étape 18 |
| pivots de renvois | 9805945 : vis décolletée 3×18 ; 50582 : vis décolletée 3×14 suivant étape 19 |
| palonnier servo | Vis M2×4 du FT90M, séparée de la visserie Tamiya |
