# Axes métalliques de roues avant

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **Tamiya 50823 — TG10 Wheel Axle**. Quantité prévue : **1 sachet de 2 axes pour les deux roues avant**.

Ces axes métalliques sont utilisés avec les fusées A7 dans la notice TT-01R. Ils évitent de faire porter la roue par l’axe de 2 mm d’un moteur.
