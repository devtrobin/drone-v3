# Notices et documents

- [Notice V3](notice-fixations-pi-5-v3.pdf) : document rédigé pour ce projet. Aucune notice constructeur du kit Ewwtrey identifiée ; ne pas confondre cette notice avec un certificat de fabricant.
- [Raspberry Pi 5, plan original](RaspberryPi-5-plan-mecanique-original.pdf) : une page, référence officielle téléchargée sans modification. Dimensions approximatives, non destinées à la production. [Source](https://datasheets.raspberrypi.com/rpi5/raspberry-pi-5-mechanical-drawing.pdf).
- [Essentra, catalogue original de fixations plastiques](Essentra-filetages-plastiques-reference-original.pdf) : 106 pages, fabricant différent. Exemple M2.5 x 0.45 inspecté à la page PDF 39 (page imprimée 150). Autres mentions M2.5 repérées aux pages PDF 35, 37, 41, 45, 47, 48, 50, 52, 59, 71, 86, 87, 88, 93. Seul le pas métrique usuel sert de repère ; aucune cote/qualité de ces articles n'est transférée au kit. [Source](https://essentracomponents.bynder.com/m/6e2e9b888468b393/original/2685970-pdf.pdf).

Les archives originales sont associées à des SHA256 dans ../assets.json. Photos, fiche commerciale, avis et statut des recherches sont conservés dans les fichiers voisins. Aucun PDF manquant ou source inaccessible n'est remplacé par une « notice constructeur » fabriquée.
