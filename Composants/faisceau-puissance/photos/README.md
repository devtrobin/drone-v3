# Images sources

Les images Klauke sont les petites vignettes de la page constructeur, archivées sans modification. Elles ne constituent pas des plans cotés. La vignette initialement appelée « plan-famille » est un logoUL : exclue de toute reconstruction. Les dimensions viennent du tableau actuel et du dessin de famille dans le catalogue.
