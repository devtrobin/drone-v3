# Paliers et supports de direction

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **P115-V3 / F-AV-V3 — supports à fabriquer**. Quantité prévue : **4 ensembles à deux roulements arrière/intermédiaires + 2 fourches avant**.

Les supports constituent l’adaptation au châssis fabriqué et reprennent les efforts ; ils ne sont pas livrés avec les engrenages ou les fusées.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| logements de roulement | Format 11 mm extérieur ×4 mm large ; ajustements à définir |
| architecture arrière | Deux appuis par arbre ; couronne et pignon dans les plans de denture retenus |
| architecture avant | Fourche à deux appuis autour de chaque fusée A7, avec ses pièces de pivot A6 |
| matière candidate | Aluminium pour platines, avec paliers séparés ; capacité d’usinage à confirmer |
