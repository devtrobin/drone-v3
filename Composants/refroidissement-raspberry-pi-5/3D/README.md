# STEP de l’Active Cooler SC1148

**Quatre variantes colorées en millimètres.** Une seule unité à acheter ; les autres fichiers facilitent la lecture ou l’implantation.

| Variante | STEP | Aperçu | Taille |
| --- | --- | --- | --- |
| Raspberry Pi Active Cooler SC1148 : detaille | [STEP](raspberry-pi-active-cooler-sc1148-detaille.step) | [PNG](raspberry-pi-active-cooler-sc1148-detaille.png) | 17.42 Mo |
| Active Cooler SC1148 : module sans cable | [STEP](raspberry-pi-active-cooler-sc1148-sans-cable.step) | [PNG](raspberry-pi-active-cooler-sc1148-sans-cable.png) | 16.54 Mo |
| Active Cooler : dissipateur 54 segments | [STEP](raspberry-pi-active-cooler-dissipateur-detaille.step) | [PNG](raspberry-pi-active-cooler-dissipateur-detaille.png) | 14.97 Mo |
| Active Cooler : implantation sans stries ni logo | [STEP](raspberry-pi-active-cooler-implantation-legere.step) | [PNG](raspberry-pi-active-cooler-implantation-legere.png) | 2.40 Mo |

Le fichier complet représente les ailettes striées, le rotor visible, le capot, les têtes de vis, les deux clips fendus avec ressorts hélicoïdaux, trois pads, le marquage du plan, quatre fils continus et leur fiche.

Les dimensions de référence sont approximatives. Toutes les cotes locales inconnues sont signalées dans les JSON. Les fils sont placés pour l’illustration, pas à une longueur garantie. Les variantes sans cordon l’omettent volontairement. La version d’implantation omet aussi les stries et le logo pour une ouverture plus rapide.

Le marquage est extrait des contours vectoriels du plan ; son relief de lecture n’est pas une gravure mesurée. Aucun moteur ni circuit interne de ventilateur n’est inventé.
