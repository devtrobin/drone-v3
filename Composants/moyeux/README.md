# Moyeux de roues

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **Tamiya 53569 — Clamp Type Aluminum Wheel Hub, 6 mm**. Quantité prévue : **4 moyeux ; jeu commercial annoncé de 4, contenu des accessoires à contrôler**.

Un moyeu serré reste sur l’axe lors du démontage de la roue. La famille Tamiya correspond au train avant retenu ; l’empreinte nominale correspond aux roues HobbyPark.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| type | Moyeu aluminium serré sur l’axe par vis |
| épaisseur | 6 mm publiée |
| interface retenue | Famille hexagone 12 mm pour axe de roue Ø5 mm ; à contrôler avec la roue HobbyPark |
| roue associée | Empreinte 12 mm, passage d’axe 4 mm ; une partie filetée M4 traverse la roue |
| goupille | Principe de montage sur goupille transversale 2×10 mm |
