Les formes du fabricant sont conservées. L’original garde ses styles ; les dérivés attribuent des couleurs de lecture et rendent le capot bleu opaque. La vue éclatée déplace seulement le capot. Pas de fils, embouts, vis de châssis ou géométrie interne supplémentaire inventée.

Le modèle natif ne détaille pas toutes les vis comme pièces séparées. Enveloppe CAO précise dans les JSON ; cotes commerciales arrondies et réserves dans [cotes.md](../cotes.md).
