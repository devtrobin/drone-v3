# Roulements de roues et transmissions

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **MR115ZZ — 5×11×4 mm ; référence documentaire SMB Bearings**. Quantité prévue : **12 : 4 avant, 4 sorties arrière, 4 arbres intermédiaires**.

Le même format couvre les roues et les arbres de réduction Ø5 mm. L’arbre intermédiaire tourne vers 7 579 tr/min à 40 km/h, sous la limite indiquée dans la fiche SMB ; charge, ajustement et lubrification restent à vérifier.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| dimensions | Alésage 5 mm, diamètre extérieur 11 mm, largeur 4 mm |
| fermeture | Deux flasques métalliques ZZ ; ne pas confondre avec MR105ZZ 5×10×4 |
| fiche SMB | Acier SAE52100, cage acier, graisse Multemp SRL |
| charges publiées SMB | 28 kgf statique (~275 N), 71 kgf dynamique (~696 N) |
| vitesse limite SMB | 45 000 tr/min avec lubrification adéquate ; pas une vitesse garantie de l’ensemble |
| équivalent de famille | Tamiya 53008, roulement 1150, sachets de quatre ; dimensions à vérifier |
