# Pignon du second étage

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **KHK SS0.5-24B**. Quantité prévue : **2 pignons, un par arbre intermédiaire**.

Il s’installe sur le même arbre Ø5 que la première couronne. Aucun réalésage d’un pignon 3 ou 4 mm n’est nécessaire.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| denture | 24 dents, module 0,5, angle de pression 20° |
| alésage | 5 mm H8 ; choisir B, pas A alésé 4 mm |
| diamètres | Primitif 12 mm ; extérieur 13 mm ; moyeu 13 mm |
| dimensions axiales | Denture 5 mm ; moyeu 11 mm ; total 16 mm |
| fixation / masse | Vis M4 ; 13 g |
| limites catalogue | Flexion 0,93 N·m ; durabilité de surface 0,059 N·m, dans les conditions du catalogue |
