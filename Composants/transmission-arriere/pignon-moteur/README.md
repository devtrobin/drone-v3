# Pignon de chaque moteur

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **Losi LOS212054 — 16T, module 0,5, alésage 2 mm**. Quantité prévue : **2 pignons, un par moteur**.

L’alésage est directement adapté au moteur, sans imposer un pignon 3,175 ou 5 mm avec bague improvisée.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| denture publiée | 16 dents, module 0,5 |
| alésage publié | 2 mm, correspondant à l’axe moteur sélectionné |
| diamètres calculés | Primitif 8 mm ; extérieur théorique 9 mm pour profil standard |
| appairage | Couronne KHK SS0.5-54A, 54 dents, module 0,5 |
