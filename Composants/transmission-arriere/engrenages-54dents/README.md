# Grandes roues dentées des deux étages

**Choix de conception du 13 octobre 2026**, effectué sous l’autorisation de sélectionner les pièces. Non acheté, non testé ; aucune garantie de performance du véhicule.

Référence : **KHK SS0.5-54A**. Quantité prévue : **4 roues dentées : deux par transmission arrière**.

La même référence sert aux deux étages, avec un alésage Ø5 directement adapté aux arbres retenus et une couronne extérieure de 28 mm.

## Caractéristiques et rôle

| Donnée | Valeur / statut |
| --- | --- |
| denture | 54 dents, module 0,5, angle de pression 20° |
| alésage | 5 mm |
| diamètres | Primitif 27 mm ; extérieur 28 mm ; moyeu 25 mm |
| dimensions axiales | Largeur de denture 5 mm ; largeur de moyeu 7 mm ; longueur totale 12 mm |
| fixation | Vis M4 dans le moyeu |
| matière / masse catalogue | Acier S45C, oxydation noire, 47 g par roue dentée |
| limites catalogue | Flexion 2,67 N·m ; durabilité de surface 0,32 N·m, dans les conditions du catalogue |
