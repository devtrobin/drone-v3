# HellermannTyton T18R 111-01919

**Colliers PA66 naturels pour l’intérieur.** Choix d’étude V3, non acheté et non testé.

100 × 2,5 mm ; épaisseur 1 mm ; PA66 naturel ; 80 N résistance minimale de boucle ; faisceau 1,5–22 mm ; non réutilisable ; non stabilisé UV.

## Utilisation et quantité

Quantité d’étude 12, à arrêter après implantation. Maintien sur embases MB2 sans écraser la gaine ; prévoir une boucle de service et retenir les fils avant les raccords.

Besoin proposé : **12** (0 ferme pour les raccordements décrits, 12 conditionnel ou d’implantation). Conditionnement fabricant indiqué : **100**, sans garantie du conditionnement vendeur.
